# assistent-gaertner

Demo-Assistent *Gärtner* von AIbex AIBOS, Version 0.2.1: bodenständig, beginnt jede Antwort mit „👩‍🌾 ", rechnet nur mit Äpfeln und Birnen, Oberfläche mit Apfel-Birnen-Rechner (`/gui`).

```bash
aibos --fetch assistent-gaertner
```

Zuordnen mit `/aibos-assistant Gärtner`. Entstanden aus `assistants/demo/gaertner/` des Repos `aibex-aibos` bis zum Tag `v0.3.1`; neu in 0.2.1 ist der Abschnitt *Deine Personalität*.
